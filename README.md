# DSE Level Up

專為香港 **DSE 考生**而設嘅**免費**溫習平台。  
網站：[https://www.dselevelup.com/](https://www.dselevelup.com/)

**全部功能免費。** 無訂閱、無 Premium、無廣告、無限題數。登入只係方便你喺唔同裝置睇返進度，**唔會解鎖任何額外內容**。

---

## 適合邊啲人？

- 想練**選擇題判斷**、睇穿常見陷阱嘅中四至中六同學  
- 想**唔使登入都先試**幾題嘅同學  
- 需要**SEN 友善**介面（字級、易讀字體、閱讀尺等無障礙設定）嘅同學  
- 想有個**情緒安全**空間溫習、唔想被遊戲化催逼嘅同學  
- 想了解題目點嚟、有冇透明度嘅**家長／老師**

本平台**唔係**考評局（HKEAA）官方網站，亦**唔保證**成績。

## 點樣開始（約 1 分鐘）

1. 打開 [dselevelup.com](https://www.dselevelup.com/)  
2. 喺首頁揀一科，或者撳「開始練習」  
3. 一節約 **10 題選擇題**，大約 15 分鐘；做錯有解析  
4. （可選）用 **Google 登入**，進度可以喺第二部裝置接住

唔想開帳戶？一樣可以練。登入只係同步進度同設定。

## 登入同私隱（學生／家長）

- **而家：** 主要用 **Google 登入**（Auth.js），方便跨裝置同步練習進度。  
- Google 登入**唔等於**我哋會將你嘅 Google 密碼存落資料庫。  
- 詳情睇 [私隱政策](https://www.dselevelup.com/privacy)。  
- 想刪帳號／資料：跟私隱頁同帳戶設定嘅指示；敏感保安問題請電郵聯絡（見下）。

我哋**唔會**用你嘅練習內容去做廣告。收集資料嘅目的係改善溫習體驗同保安，唔係賣你嘅資料。
