## 點樣由貼紙表整出嚟

原檔係 **JPEG**，張圖入面嗰個「透明格仔」係畫上去嘅像素，唔係 alpha channel。
所以要靠演算法分辨底同圖，做法（`scripts/` 冇留腳本，一次性處理，步驟記喺呢度）：

1. **實測校準**，唔係估：格仔底係中性灰 **177** 同 **198** 兩種；
   貼紙描邊係純白 **255**；圖本身嘅奶油色偏暖（R > B），中性度測試篩得走。
2. 由四邊做 **flood fill**，只剷【連得返出面】嘅背景 ——
   杯身、書頁嗰啲淺色喺圖內部連唔到出面，唔會被剷穿。
3. 白色描邊連住格仔，會一齊剷走。**呢個係想要嘅**：
   白色描邊落喺暖暗底頁面會變成一圈白光暈。
4. 輸出 RGBA PNG，再減半尺寸（網頁最大只顯示到 ~200px，唔使原尺寸）。

## ⚠️ 有兩隻【冇】收錄，唔好補返上嚟

貼紙表原本有七隻。以下兩隻含第三方註冊商標，按憲章 §4（零版權侵犯）唔收：

呢個站係公開、面向 12–18 歲用戶嘅教育平台。喺頁面長期擺一個帶住
Nintendo／Apple 商標嘅吉祥物，同「改寫題目避開 HKEAA 版權」係同一條線 ——

要用嘅話要重畫件裝置（去 logo）先，唔係喺呢度加返個檔就得。
`lib/mascot.ts` 有一條測試鎖住呢個決定，見 `POSES` 上面嘅註釋。
