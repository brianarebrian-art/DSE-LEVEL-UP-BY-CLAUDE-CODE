## 1. 資產

| 資產 | 敏感度 |
|---|---|
| 學生雲端進度／設定（Google `sub`） | 高（學習軌跡） |
| 帳戶／session（Auth.js／未來 Better Auth） | 高 |
| 題庫內容與 provenance | 中高（考試誠信／版權） |
| 推送 endpoint（無 user_id） | 中（裝置假名） |
| 公開頁／SEO 內容 | 低 |

## 2. 威脅角色

| 角色 | 目標 |
|---|---|
| 匿名訪客 | 濫用 API、刮題、DoS |
| 登入學生 | 讀寫自己資料；誤觸刪帳 |
| 惡意同儕 | IDOR 讀他人進度、竄改 |
| 外部攻擊者 | 憑證盜用、XSS、供應鏈 |
| 內部／CI | 誤 deploy、secret 外洩 |

## 3. 主要攻擊面（摘要）

| 面 | 現有控制（已核對／部分） | 殘餘 |
|---|---|---|
| `/api/*` | `proxy.ts` IP rate limit；多數 catch 用 `safeLog` | FIX-002 scrub Draft；歷史 log 清理要 R3 |
| 刪帳 | FIX-003 唔回表名 | 人工覆核仍建議 |
| JSON body | FIX-004 串流上限 | — |
| 推送訂閱 | FIX-001 Draft token；prod 無表 | 開推送前必修＋套用 0026 |
| Auth flip | Better Auth 休眠 | 開 email／password 要驗證郵件＋G 決策 |
| XSS／CSP | CSP nonce；無 session replay | 持續內容衛生 |
| 題庫擷取 | 公開練習池有意可讀；原始稿非公開 | I 包版權閘 |
