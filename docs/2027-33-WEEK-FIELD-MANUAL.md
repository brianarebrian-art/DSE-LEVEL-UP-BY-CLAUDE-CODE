## 三、成功重新定義

> **「全港第一」唔係自行宣稱嘅標題，係可核查證據嘅自然結果。**

| 面向 | 2027-04-07 前必須建立嘅證據 | 衡量方式 |
|---|---|---|
| **內容可信** | 每條上線題目有原創性說明、機械閘通過、真人簽核紀錄 | `decisions.json` + 合併保護 log |
| **學生尊重** | 全站零紅叉、零倒數恐慌、零能力標籤、零強迫回訪 | 內部任務劇本走查 10 個情境 |
| **私隱最小化** | 零新增遙測、零個人錯題 DNA、零學生資料追蹤 | 程式碼 diff 審核 + 網絡請求檢查 |
| **可靠交付** | P0 故障 4 小時內可回滾、錯誤答案鍵 24 小時內暫停修正 | 演練紀錄 + 回滾手冊 |
| **負責任溝通** | 所有對外資產經事實、版權、語氣、年齡／同意檢查 | 待批准資產庫 + 審核表 |

## 六、紅線與停止門

Claude Code，以下情況一出現，**你唔可以做，唔可以「先做再問」**：

| 觸發器 | 你必須立即停止並提交安全備忘 |
|---|---|
| 有人要求你私訊 / WhatsApp / Signal 聯絡學生 | 備忘須含：目的、兩個不接觸學生嘅替代方案、保障風險 |
| 有人要求新增資料欄位 / 事件 / cookie / 追蹤 | 備忘須含：最小資料表、用途、保存、刪除、「不收集」替代方案 |
| 有人要求收集學生見證 / 升分故事 / 相片 | 備忘須含：不用個案嘅功能說明替代資產 |
| 有人要求你發社交貼文 / DM / 合作邀請 | 備忘須含：目標、草稿、證據、受眾、版權／私隱、批准欄 |
| 有人要求加入醫療級聲稱 / 情緒診斷 | 備忘須含：真實服務邊界、官方外部資源、風險 |
| 有人要求用可辨識未成年人做影像 | 備忘須含：成年／物件／非辨識替代規格、版權 |
| 有人要求機器自動入庫題目 | 備忘須含：真人審核不可替代性說明 |
| 有人要求繞過 gate / 合併保護 / 真人簽核 | 備忘須含：風險分析、兩個替代方案 |
