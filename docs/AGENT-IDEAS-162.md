## 0. 給 Claude Code 的操作指令（先讀本節）

### 0.1 本文件是什麼

161 個編制崗位，每位提出三條互不重疊的改善建議，針對兩大痛點：

- **P1 內容不足**：變體少、步驟淺、marking scheme 粗糙、多角度分析不足。
- **P2 超綱／失準**：大學層級概念、非香港術語、與考評框架脫節、抄襲風險。

每條建議的固定結構：
- **Idea 1**：解決內容不足（Archetype Masking 變體、M/A/C/L/pp 分項評分、關鍵詞矩陣擴充）
- **Idea 2**：解決超綱／失準（`term-guard` 攔截、對齊 HKEAA 考評框架 2025–2028）
- **Idea 3**：題型專屬與機制優化（計算機程式驗證、Data File 防盲抄、12 篇範文跨篇連結、干擾項分析卡等）

### 0.2 執行工作流（不可跳過）

```
選定崗位建議（用 ID，例如 CHI-P1A）
  → 對照 §0.4 現有資產，確認不重造
  → 實作（改 code／出題／改守閘）
  → 若產出題目：一律寫入 scripts/qbank/drafts/*.json
  → 跑 npm run qa（term-guard + validate-banks + i18n-guard）
  → 人手 review-drafts.mjs → promote-drafts.mjs 方可入庫
  → 更新 docs/agent-ideas-162.json 的 status
```

### 0.3 硬性約束（違反即作廢）

| 約束 | 內容 |
|---|---|
| **機器永不自動入庫** | Agent／腳本產出一律入 `drafts/`；只有真人經 `promote-drafts.mjs` 方可入庫。 |
| **零版權侵犯** | 禁複製或「改少少數字」任何歷屆試題；一律 Archetype Masking 原創改寫；禁「年份＋卷別＋題號」組合。 |
| **術語紅線** | 共用品（非公共財／公共物品）、企業家職能（非企業家才能／創業精神）；經濟科禁收入彈性／交叉彈性／點彈性；物理 g = 10 m/s²；化學 RTP 24 dm³/mol；BAFS 直式報表（禁 T-form）；數學禁偏微分／洛必達法則。 |
| **語言分層** | 學術層 100% 標準書面語／專業英文；UI 情感層可用廣東話，但禁「FAIL」「錯」等打擊字眼。 |
| **難度分佈** | 每批次 3:5:2（基礎 30%／中等 50%／困難 20%）。 |
| **零虛構統計** | 禁生成「X% 考生失分」類數據；如引用須標明模擬數據。 |
| **解析規範** | 選項會洗牌，解析一律引「內容」不引字母（A／B／C／D）。 |
| **範文限制** | 中英文寫作只提供大綱與評分準則，示範段落不超過 100 字，禁完整可抄襲範文。 |
| **成本** | 守閘、腳本、規則層一律 $0；付費 LLM 生成須人手 gate。 |
