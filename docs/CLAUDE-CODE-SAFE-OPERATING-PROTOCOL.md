# Claude Code 長期安全執行協議：DSE LEVEL UP 至 2027 中文 DSE

> **有效協議：** 本文件與 `docs/2027-SAFETY-REPLAN-DECISIONS.md`、`docs/2027-SAFE-EXAM-READY-STRATEGY.md` 和 `docs/CLAUDE-CODE-2027-SAFE-DAILY-PLAN.md` 共同構成唯一可執行指令。任何舊日曆、舊策略或舊協議一律只作歷史參考。

## 一、每次啟動的強制流程

1. 讀取 `AGENTS.md`、`SKILL-dse-sop-harness.md`、本協議、安全決定、策略、日曆及 `docs/today_action.md`。
2. 以香港時間定位今天的唯一工單。若不在 2026-08-24 至 2027-04-07 範圍，停止並更新 `docs/today_action.md` 說明狀態；不可借用其他日子任務。
3. 先寫不超過十行的範圍：目標、非目標、受影響路徑、資料邊界、外部動作、驗收、回滾。
4. 只做當天唯一主指令。採取最小、可測、可逆改動；每個新／改函式最多 50 有效行；不順手重構或新增 SDK、資料欄位、通知、追蹤、帳戶依賴或外部行動。
5. 按範圍運行 `npm run lint`、`npm run test`、`npm run qa`、`npm run qa:budget`、`npm run build`。任何面向學生的流程另須完成手機、鍵盤、200% 縮放、減少動態、無登入及錯誤狀態走查。
6. 以安全證據包完結，更新 `docs/today_action.md`；只列可核查證據，絕不寫入機密、實際學生資料、未經批准的公開說法或個人故事。

## 二、立即停止的觸發器

以下任一情況出現時，Claude Code **不可先做再問**。停止工程或內容工作，改交付 `安全停止備忘`，等待 Brian／Yuna 的明確書面決定。

| 觸發器 | 禁止動作 | 安全停止備忘必含 |
|---|---|---|
| 未成年學生 | 私訊招募、DM、WhatsApp／Signal 跟進、一對一輔導、依脆弱性選人、要求學生感謝或回訪。 | 產品目的、至少兩個不接觸學生的替代方案、保障風險。 |
| 個人資料／遙測 | 新資料欄位、事件、cookie、SDK、表單、同步、分析、日誌、匯出或人工閱讀個人作答。 | 最小資料表、用途、保存、刪除、拒絕後行為，以及「不收集」替代方案。 |
| 個案與故事 | 見證、升分故事、相片、DM 截圖、可辨識引述、錯題曲線、情緒紀錄。 | 不用個案的來源／功能／公開修正替代資產。 |
| 對外行動 | 貼文、電郵、DM、合作邀請、社群回覆、公開數字、外部檔案交付。 | 目標、草稿、證據、受眾、版權／私隱、是否有未成年風險及單次批准欄。 |
| 情緒／健康 | 診斷、醫療級聲稱、治療暗示、假裝有人即時輔導、危機訊息改動。 | 真實服務邊界、官方／已核對外部資源、風險與所需審閱。 |
| 影像與人物 | 可辨識未成年人、人物年齡／同意不明、熬夜／過勞美化、創辦人即時脆弱敘事。 | 成年／物件／非辨識替代規格、版權及批准需求。 |

## 三、固定紅線

| 面向 | 不可做 | 必須維持 |
|---|---|---|
| 題庫 | 複製 HKEAA／第三方題目、機器自動入庫、未簽核發布。 | 原創平行改寫、機械閘、真人逐題簽核、合併保護、預覽抽查。 |
| 長答 | 自動批改、打分、估官方等級、收集作文作分析。 | 自評清單、結構提示、例子及真人參考；不儲存個人長答內容。 |
| 學生體驗 | 倒數恐慌、紅叉羞辱、能力標籤、同儕比較、解鎖／強迫回訪。 | 具體下一步、自由略過、休息出口、香港繁中、低壓與可及性。 |
| 免費與誠實 | 付費牆、廣告、假用戶、假見證、假在線、假合作、未證實排名。 | 100% 免費、可查來源、公開更正與不確定性表述。 |
| 考前穩定 | 2027-04-04 後新增功能、題庫批次、外部活動、資料收集、重構。 | 只修 P0、已證實內容錯誤或官方日期／連結；每項真人單次批准。 |
