# 混合課題逐題選修對應 —— 2026-09-26

> **決定：** Yuna（COO）2026-09-26，按憲章 §18：「要將地理、ICT、企財幾科嘅混合課題加入選修對應，呢樣要逐條題分開。」

## 做法

- `scripts/qbank/gen-question-scope.mts` 按下列規則，逐題判斷下表各課題的每一條題目，
  結果寫入 `data/questions/question-scope.generated.ts`（`npm run qbank:question-scope`）。
- 只列出**只屬某一個選修**的題目；沒有列出的題目為「共用」，所有學生都會見到。
- 練習頁 `isQuestionInScope`（`lib/electives.ts`）先看逐題對應，再看課題對應（`TOPIC_SCOPE`），兩者都沒有即為共用。
- 規則不確定時，一律歸「共用」：把必修題篩走，比多出一條選修題更差。
- 分類由 Claude 按課程及評估指引逐個題目家族判讀，**未經學科老師覆核**。
- 迴歸鎖：`data/questions/__tests__/question-scope.test.mts`。在這些課題加題而未重新生成，測試會失敗。

## 規則及依據

### 地理 —— 選修「天氣與氣候」（課程及評估指引 2022，p.16）

指引說明此選修延伸必修的基本概念。
- **選修：** 降雨類型（對流雨、地形雨、鋒面雨、雨影）、熱帶氣旋、季風、氣溫遞減率、相對濕度、氣壓、海陸對氣溫的影響。
- **共用：** 讀氣候圖、年溫差計算、天氣與氣候的分別、城市熱島、厄爾尼諾。這些屬必修單元也會用到的技能或概念，或指引未有清楚劃分。

### ICT —— 選修「資料庫」

- 必修 A 只涉及單一資料表及簡單 SQL（p.25）。
- **選修（p.47–50）：** 外鍵、一對多、多對多、聯繫表、多表連接、規範化、範式。
- **共用：** 記錄、欄位、主鍵、查詢、排序與篩選、DBMS、資料冗餘、資料表大小計算、索引。
  索引指引未有清楚劃分，歸共用。

### 企財 —— 會計組／商業管理組（2027 年指引）

- **會計組選修（p.17–21）：**
  - 期末調整：應計、呆帳及呆帳準備、存貨估值、損耗；
  - 折舊（全文只在會計組出現）；
  - 合夥、有限公司、銀行往來調節表；
  - 謹慎等會計原則（商管組必修只列企業個體、持續經營、歷史成本、一致性、應計）；
  - 成本會計：成本分類、邊際貢獻、收支平衡、目標利潤、停產決策；
  - 投資比率（每股盈利、股息保障、市盈率）。
- **商業管理組選修（p.25–27）：**
  - 財務管理：融資來源、預算及現金預算、回本期等資本投資評估、營運資金管理；
  - 人力資源管理；
  - 市場營銷（4P、定價策略、市場區隔、目標市場、品牌、產品生命周期、顧客關係）。
- **共用：**
  - 比率分析：會計組（p.20）及商業管理組財務管理（p.25–26）都有，故兩組都見到。
  - 基本會計：會計等式、複式記帳、試算表、獨資商號報表（商管組必修 Basics of Accounting，p.22）。
  - 管理職能（會計組必修 Basics of Management，p.14）。
  - 成本加成、營運資金、單利息、貨幣時間價值、債權證（個人理財必修亦涵蓋）。
