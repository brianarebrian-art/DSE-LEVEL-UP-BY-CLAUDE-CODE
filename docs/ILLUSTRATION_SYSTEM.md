# 插圖設計系統指引 (Illustration Design System)

本指引規範 DSE Level Up 原創向量插圖之視覺語彙與應用規範。

## 1. 核心精神與視覺氛圍
- **核心定位**：服務香港 DSE 文憑試中學生，消除備考焦慮，營造如清晨圖書館般的沉靜專注氛圍。
- **色彩哲學**：基於莫蘭迪色彩（Morandi Palette），低飽和度灰綠、暖陶土、深暖灰與米白底色，杜絕刺激性紅綠色塊。
- **幾何構成**：基礎 viewBox 採用 `0 0 160 120`，結合柔和圓角、溫潤曲線與點陣裝飾。

## 2. 場景分類與規範

### A. 空狀態插圖 (`empty-state.svg`)
- **語意情境**：學生首次造訪錯題本、未篩選到任何試題或清單暫無記錄。
- **構成要素**：翻開的溫暖筆記本、微光知識點、平靜的導航指針。
- **伴隨元件**：必須伴隨明確的文本指引（例如「仲未收藏過」）與積極的下一步行動按鈕（例如「開始練習」）。

### B. 錯誤與重試插圖 (`error-state.svg`)
- **語意情境**：網路連線中斷、路由渲染異常或伺服器回應逾時。
- **構成要素**：守護盾牌、導向信標燈與引導虛線軌道。
- **伴隨元件**：告知「練習紀錄存喺呢部裝置度，冇受影響」，提供「試多次」與「返回首頁」捷徑。

## 3. 開發實作準則
- 存放位置：`src/assets/illustrations/*.svg` 與 `src/components/ui/Illustration.tsx`。
- 零外部圖像依賴，全代碼打包內嵌，杜絕 CDN 遺失風險。
