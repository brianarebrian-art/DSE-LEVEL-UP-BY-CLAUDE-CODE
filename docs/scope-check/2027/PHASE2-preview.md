未作判斷前的觀察（不是結論）：每五題的正確答案相同，只換了數字；解析引用選項內容，沒有位置式字眼。

**預計判斷方式：**
1. 下載對照表所列、適用於 2027 年的物理科課程指引，查三件事：有沒有質量密度；有沒有列明初中科學為假定已掌握的前備知識；「熱和氣體」一章涉及的壓強內容。
2. 按決定第七節第 1 點：先判斷題目考的是初中前備計算，還是高中物理指定概念。不因出現「密度」二字而判斷。
3. 每題記錄：考核知識、技能、公式、推定卷別（卷一必修，inferred）、推定單元、是否前備知識、是否選修；對應的指引章節及頁碼；信心；是否需要真人覆核。
4. 可能結果：
   - 如指引把密度列為前備知識 → PASS 或 REVIEW。
   - 如指引沒有，而題目不考任何高中物理概念 → REPLACE。
   - 預計不會出現選修問題，亦不需要查考評局文件。

**預計替換題：** 0 至 10 題。如判 REPLACE，替換題會在同一課題的合法內容內出題（例如「熱和氣體」的氣體壓強），選擇題、容易、單一公式計算，每題標明依據的指引章節。
