## 三、§7「零故障保證」撞 §16.D

```
docs/charter.md:280  **SEN 功能狀態：全部上線。** ADHD／抑鬱症／焦慮症／讀寫障礙友善系統常駐，零故障保證。
```

§16.D 明文禁止「將 build-time 測試講成 runtime 防護」，判例正正就係 SEN 相關嘅
「自動攔截 3Hz 閃爍」。「零故障保證」係一個**冇人驗證得到**嘅絕對聲稱：

- 冇 runtime 監測；出事嘅話冇機制知。
- 一個真係靠 SEN 功能嘅學生，睇到「零故障保證」可能因此唔開自己部機嘅輔助功能。
  呢個同 §16.D 嗰宗判例係同一種傷害。

**建議條文：**

> **SEN 功能狀態：全部上線**（OpenDyslexic 字體、防跳行閱讀尺、柔和呈現、
> 專注燈、休息日護盾、呼吸急救室）。每項都有迴歸測試鎖住，改壞咗會喺 CI 紅。
> ~~零故障保證~~ —— 刪。冇 runtime 監測就唔可以講「零故障」（§16.D）。
