# docs/24-strategy-advice-2026-11-26.md — 創辦人策略問答（可執行建議）

> 對象：二人團隊、無學科教師、無額外 LLM API、中學生為主、免費全科平台。  
> 原則：最小必要、可驗證、可回滾、唔虛報。

## 1. 點用 AI Agent 收集同分析真實用戶數據？

**只收集練習所需嘅最小事件**（已喺 2B C3 字典）：題目 ID、對錯、用時、科目／課題、匿名 session、練習模式。  
**唔收集**身份證、電話、精確位置、情緒診斷、鍵盤錄影。

做法：

1. 同意閘：`calibration.v1`；可撤回。  
2. Server 寫入 `calibration_events`（RLS 鎖死 anon）。  
3. Agent 只讀**聚合表**（每題答對率、n、CI），唔讀個人時間線。  
4. 每週產出一份「錯題類型 × 課題」報告；人工只睇聚合。

冇額外 LLM 時：用 SQL／腳本做分析即可，唔使把原始作答送去第三方模型。

## 2. 點用 AI Agent 處理用戶數據？

| 准 | 不准 |
|---|---|
| 聚合統計、異常偵測（過快作答）、題目難度校準 | 把原始答案／電郵送入外部模型 |
| 分類用戶回報（答案錯／翻譯／技術）— 可用規則＋關鍵詞 | 自動診斷精神健康 |
| 產生「下一步練習建議」用本地規則／既有 mastery | 以單一數據點懲罰學生 |

處理鏈：收集 → 假名 → 聚合 → Agent 讀聚合 → 建議 → 人類批准先改產品。

## 3. 網絡安全經驗有限，點保障使用者資料？

保守清單（本 repo 已部分具備，繼續強制）：

1. Supabase RLS 全開；用戶表零 anon policy。  
2. Service role 永不入前端；`secret:scan` 入 CI。  
3. 寫入只經 server API；輸入長度／類型限制。  
4. Sentry 關 Replay；scrub token／email；唔附加答案。  
5. 生產 migration 前：schema 對帳 + backup drill。  
6. 答案鍵：練習 session 路徑唔回傳（flag）；全庫切斷另批。  
7. 事故本：誰可讀什麼、24h 內停寫、通知模板。

唔要自己「學完再上安全功能」——**預設拒絕**，只開最小必要。

## 4. 點用 AI 做網站保安維護？

每週／每次部署前固定腳本（唔靠「感覺」）：

- 依賴漏洞（`npm audit`／隔離 vuln-tsunami 桌面監控）  
- secret 掃描、RLS／Storage／RPC 清單 diff  
- 異常 API 速率、異常下載  
- 答案外洩掃描（bundle 含 `correctIndex` 路徑）  

AI Agent 角色 = **讀報告、排優先級、開修復 PR**；P0／P1 停發布。

## 5. AI 會點影響中學教育科技？

短期：個人化練習、錯題診斷、雙語支援會變常態；但**公信力**仍取決於是否可驗證、是否超綱、是否冒充官方。  
對 DSE Level Up：優勢唔係「有 AI」，而係 **免費 + SEN／情緒安全 + 透明限制**。AI 只係加速改題同分析；冇教師時必須公開「未經註冊教師審定」。

## 6. AI 可唔可以改善中學生情緒健康？

可以做：**溫和回饋、拆細任務、休息建議、本地求助資源、減少羞辱設計**。  
唔可以做：診斷、開藥、承諾治療、扮演輔導員、儲存危機對話當訓練數據。  
偵測到自殘／自殺意圖 → 顯示香港本地緊急資源 + 鼓勵找信任成人；**唔繼續傾方法**。

## 7. 無 AI agent 經驗，點提升題庫優化效率？

在「無額外 LLM」約束下：

1. **確定性閘**全量跑（格式、重複選項、羞辱語、相似度 stub）。  
2. **用戶回報優先隊列**（已有 report API）→ 48h 內修／withdraw。  
3. Cursor Agent 分批改高頻科；每批有 ledger + 可回滾。  
4. 最終一次簽署，但簽署範圍 = 已 `ADVERSARIAL_PASSED` 清單，唔係全庫口頭保證。  
5. 公開修正日誌建立信任（比虛假「已審核」有用）。

## 8. 點提升信譽同口碑（免費之外）？

| 做 | 唔做 |
|---|---|
| 公開版本／錯誤修復紀錄／已知限制 | 虛構教師推薦、用戶見證 |
| 折疊披露「未經註冊教師審定」 | 暗示官方或「等同考評局」 |
| SEN／情緒安全真實走查證據 | 焦慮倒數、羞辱錯答 |
| 「我學懂咗咩」弱點報告 | 只晒分數同排名 |
| 請 SENCO／輔導人員自願審產品流程（非逐題） | 未同意用學生個案宣傳 |

**免費係入場券，可信係留存。** 口碑來自「錯題會修、限制講清楚、練習真係幫理解」。

## 9. 對「30 日全量難 10%」喺無額外 LLM 下的裁決

**做唔到誠實全量。** 繼續執行：全量盤點與狀態標記 + 可驗證試點／高頻改寫 + 一次簽署已就緒批次。其餘 `LEGACY_UNCALIBRATED`。詳見 `docs/23-no-external-llm-policy.md` 與 `docs/19-final-scorecard.md`。
