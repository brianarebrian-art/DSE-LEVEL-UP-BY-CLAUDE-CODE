# 等級估算校準紀錄

**版本**：v4（2026-08-23）
**取代**：《等級預測算法 v3 — HKEAA 2025 校準版》§4.4 所要求的逐科 `k` 擬合
**相關檔案**：`lib/mastery.ts`、`lib/levelDistribution.ts`、`lib/levelDrift.ts`、
`data/dse-2025-level-distribution.json`、`data/dse-level-drift.json`

---

## 一、規格書要求了什麼

v3 規格書 §4.4 訂明逐科校準程序：

> 1. 讀取該科目標累積百分率
> 2. 生成 10,000 個模擬考生，能力值按常態分佈
> 3. 用該科題庫的實際 t1/t2/t3 比例跑模擬作答
> 4. 用 `k = 1.00` 起手，跑出輸出分佈
> 5. 用二分搜尋調整 `k`，直至四條線同目標值的絕對差全部 ≤ 2 個百分點
> 6. `k` 凍結，寫入該科設定

並要求（§七 測試 7）以此作為「v3 存在的理由」。

---

## 二、本批**不執行**該程序。理由

### 2.1 該程序是循環論證

程序的第 2 步「生成 10,000 個模擬考生，能力值按常態分佈」——**這個能力分佈是假設出來的**。
第 3 步的作答模型（某能力的考生答對某難度層的機率）同樣是假設出來的。

於是第 5 步「調整 `k` 直至輸出吻合表 5a」**永遠調得到**：只要有一個連續參數，
配上兩個可自由設定的假設，總能令輸出對上任何目標分佈。

換句話說，這個擬合**沒有引入任何新資訊**。它把一個假設（門檻表）換成另一組假設
（能力分佈 + 作答模型 + 擬合係數），而且新的一組更難被人看見。結果是造出一個
「已校準」的外觀 —— 規格書自己在 §4.4 的警告「`k` 不是手調的魔術數字」，
在這個結構下其實守不住：`k` 確實不是手調的，但生成它的兩個假設是。

### 2.2 真正的識別問題

要把「本平台的表現」映射到「DSE 等級」，需要**對照數據**：同時擁有
（a）平台量得到的表現、（b）真實 DSE 成績的學生。

本平台目前**一個都沒有**。沒有對照數據，這個映射在數學上是識別不到的
(unidentified)。任何聲稱準確的算法，若沒有這批數據，其準確度是聲稱出來的。

規格書自己的 Phase C（放榜季邀請舊用戶自願回報成績）是唯一的出路，
且明確標示為「要用兩三年慢慢儲」的資產。這一點規格書判斷正確。

## 三、v4 的做法

不用擬合係數掩蓋假設，改為**把假設減到最少，並且逐一寫在使用者眼前**。

| 步驟 | 數值來源 | 是否我方訂定 |
|---|---|---|
| 猜測校正 `(obs − 0.25) ÷ 0.75` | 四選一 MC 的數學事實 | 否 |
| 三層權重 3 : 5 : 2 | 題庫出題比例（憲章 §12），與 DSE 卷面一致 | **是**（已於 `/prediction-method` 明示） |
| 掌握度 → 考生百分位 | 恆等映射 | **是**（唯一未經驗證的假設，已明示） |
| 百分位 → 等級 | 考評局表 5a 各級累積百分率，逐科 | 否 |
| 區間加闊 | 考評局表 7c 該界線十年標準差 | 否 |

**逐科差異完全來自公布數據**：英文要全港前 10.1% 才是第 5 級，物理前 26.3% 已經是。
v3 需要為每科擬合一個 `k` 才做得到這件事；v4 直接查表就有，而且查的是事實。

我方訂定的數值由 v3 的**七個門檻 + 每科一個 k**（合共 24 科 × 1 + 7 ≈ 31 個）
減至**兩項**（一組權重、一個恆等假設）。

## 四、可測量的不確定性

| 層 | 來源 | 是否量得到 | 目前數值範圍 |
|---|---|---|---|
| ① 抽樣誤差 | Wilson 區間（95%） | ✅ 算得出 | 隨題數變化，480 題時約 ±17 個百分點 |
| ② 界線年度漂移 | 表 7c 2016–2025 標準差 | ✅ 量得到 | 各科 5+ 界線 sd 0.41–3.98 個百分點 |
| ③ 「平台表現 = 真卷表現」 | — | ❌ 量不到 | 需要 Phase C 對照數據 |

第 ③ 層是本估算最大的不確定性來源，而它**沒有數值**。`/prediction-method` 與結算頁
均以紅色標示，不容許被前兩層的精確數字掩蓋。

## 五、關於規格書 §七 測試 7

「10,000 模擬考生跑完，四線同表 5a 絕對差 ≤ 2 個百分點」**不予實作**。

理由同 §2.1：模擬考生由我方假設生成，因此該測試檢驗的是「我方的模擬是否
自洽」，不是「估算是否準確」。一個通過該測試的算法，可以完全不準確。
寫一個必然通過的測試，等於為自己發一張證書。

**改為實作的測試**（`lib/__tests__/mastery.test.mts`，23 條）：

- 源碼中不得再有任何自訂等級門檻（掃描 `LADDER`/`THRESHOLD` 及 v3 那七個數值）
- 等級必須由 `subjectDistribution()` 查得，逐科不同（以英文／物理實測差異）
- 亂按一千次的洩漏率有上限，且封頂於第 2 級 —— **並明確記錄無法達到 0%**
- 樣本量上限鎖不得用於遮蓋不確定性（先判斷後封頂的次序）
- 永不輸出單一等級

## 六、下一次更新

考評局每年放榜後發布新一年的表 5 與表 7。屆時：

```bash
python3 scripts/qbank/extract-hkeaa-2025.py ~/Downloads/<新的表5 PDF>
python3 scripts/qbank/extract-hkeaa-drift.py ~/Downloads/<新的表7 PDF>
npm test
```

兩個腳本均以座標分欄，不依賴文字次序。`data/*.json` 內的 `source.extractedOn`
與 `year` 必須隨之更新（憲章：數據年份必須顯示）。

若屆時已累積 ≥ 200 份自願回報的真實成績，則第 ③ 層首次變成可量度 ——
那才是真正的校準，本文件應隨之改寫。
