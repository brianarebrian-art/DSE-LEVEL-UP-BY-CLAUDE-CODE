# F 組 —— 新功能提案（唔係缺陷）

呢兩項係外部報告提出嘅**新想法**，唔對應任何現存缺陷。
列喺度只係為咗唔好靜靜哋消失。

## F1 ⬜ 由錯因揀題（`mode=cause`）

學生撳「專攻審題陷阱」，系統由本機錯因紀錄揀題：審題陷阱 → 題幹命中指令字
詞庫嘅題；運算粗心 → 記過 C 嘅課題入面有數式嘅題；概念盲區 → 記過 A 嘅 `topicId`。
純本機、$0、照守 3:5:2。

⚠️ **實作註記：** 報告寫「命中 `CMD_RE`」。個正則確實存在
（`components/CommandWordText.tsx:16`），但佢係 module-local、**冇 export**，
而且擺喺一個 `'use client'` 組件入面。揀題邏輯要用，就要先將佢搬入 `lib/`
再兩邊 import —— 唔係「攞嚟用」咁簡單，而複製一份出嚟就會出現兩個詞庫各自漂移。

- ⬜ **(a) 值得做，出 Phase 1 impact report**（超過 3 個檔，§4）
- ⬜ **(b) 唔做**
- ⬜ **(c) 遲啲再講**

## F2 ⬜ 分享卡改「錯因破解卡」

同 **A2 選項 (b)** 係同一件事。喺 A2 剔就得，呢度唔使重複剔。
