# docs/05-difficulty-model.md — 參數化難度模型

> 狀態：草稿代理指標（D1）  
> **這不是實測難度。** 任何對外文案不得把本模型當成已證明的「難 10%」。

## 維度

| 代號 | 維度 | 取值 |
|---|---|---|
| C | 認知層次（記憶→創造） | 1–6 |
| S | 獨立推理步驟數 | 1–10 |
| R | 表徵轉換（文／圖／表／式） | 0–2 |
| D | 干擾強度 | 1–5 |
| U | 情境陌生度 | 1–5 |
| M | 跨課題組合 | 1–3 |

## 公式（起始權重）

```
DF = 0.30·C + 0.20·S + 0.15·R + 0.15·D + 0.10·U + 0.10·M
```

權重須用真實作答數據重新擬合（Sprint 4+）。未擬合前 DF 只寫入草稿元數據。

## 分級標籤

| 標籤 | 操作定義（草稿） |
|---|---|
| EASY | DF ≤ 對照卷中位數 − 0.8σ |
| FOUNDATION | −0.8σ … −0.3σ |
| STANDARD | ±0.3σ |
| CHALLENGING | +0.3σ … +0.6σ |
| DSE_PLUS_10 | **意圖：** 對照真題 DF 中位數 **+0.4～0.6σ**（約對應答對率下降 8–12%） |
| EXTENSION | > +0.6σ 且仍在課程內 |

`DSE_PLUS_10` 在未有等百分位實測前，狀態必須為 `LEGACY_UNCALIBRATED` 或 `CALIBRATION_INSUFFICIENT`，**不得**對外標「已達標難 10%」。

## 假難（禁止）

超綱、語意不清、答案爭議、資料不足、圖表／計算錯誤、選項重複矛盾、為難而難、鼓勵純背誦。

## 與現有 `easy|medium|hard` 映射

| 現有 | 草稿映射 |
|---|---|
| easy | EASY / FOUNDATION |
| medium | STANDARD / CHALLENGING |
| hard | CHALLENGING / DSE_PLUS_10（僅當維度上調且過閘） |

試點改寫：在不改課程範圍下，優先提升 D（干擾）與 S（步驟），避免只加長題幹。
