## Reporting a vulnerability

Email **dselevelup@gmail.com** with:

- Affected URL or component
- Steps to reproduce (no destructive production probes)
- Impact on student data or exam integrity

Please **do not** open a public GitHub issue for sensitive findings.

## Scope

In scope: authentication, session sync, account deletion, API authorization, injection, secrets exposure.  
Out of scope without prior written OK: load testing production, social engineering students, accessing other users’ accounts.

## Response

This is a small volunteer-run free project. We aim to acknowledge reports and triage; there is no paid bug bounty.
