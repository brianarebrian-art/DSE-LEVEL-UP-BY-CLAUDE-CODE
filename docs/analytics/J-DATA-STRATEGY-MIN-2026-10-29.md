# J · 最少真實資料策略＋AI／Agent 分析守則（DRAFT）

狀態：**待批准** · 2026-10-29（香港時間）  
受眾：創辦人一頁決策；對齊 `docs/analytics/J-MIN-EVENTS-AND-WEEKLY-DECISION-2026-10-29.md`。  
產品現實：免費香港 DSE 學生為主；Session Replay **預設唔開**；禁止未批新付費 SDK。

## 1. 一句原則

只收集「能改善產品／題庫／穩定度」嘅最少行為訊號；**唔**建立個人成績故事、情緒檔案、或雲端 SEN 診斷標籤。AI／agent 只准做**聚合／匿名趨勢**同**題庫／系統**建議，唔准對單一學生做「預測等級／心理畫像」。

## 2. 真實資料：收咩／唔收咩

### 2.1 建議收（產品決策用）

| 類別 | 例子 | 粒度 | 用途 |
|---|---|---|---|
| 漏斗事件（J 白名單） | `practice_started`／`practice_completed`／可選 `question_answered`／`explanation_viewed` | 科／難度／對錯；**唔**要題目全文 | 完成率、流失點 |
| 系統健康 | `auth_sync_error`（聚合）；Sentry 錯誤（已有） | 錯誤類型計數 | 登入／同步阻礙 |
| 平台既有 | Vercel Web Analytics、Speed Insights | page／perf 聚合 | 載入／路由問題 |
| 匿名計數（已披露） | `practice_counts`、部分 feedback | 無身分／弱身分 | 粗用量 |
| 題庫營運（非個人） | 壞題舉報、收起／待審狀態 | 題目 id | 題目優先 |

上表事件**唔自動等於已實作**——以 J-MIN 白名單批准同埋埋點 PR 為準。

### 2.2 登入同步資料（產品功能，唔當 analytics 金礦）

登入後雲端同步（進度、課題累計、未完成節）係為**跨裝置繼續做**，用途應維持私隱頁承諾。  
分析時：**預設唔**由 agent 讀個人 `user_progress` 列去做週報；週報用事件聚合／錯誤聚合。

### 2.3 禁止收／禁止上雲標籤

| 禁止 | 理由 |
|---|---|
| 密碼、token、完整 email、raw PII | J-MIN 事件禁附帶 |
| 題目全文、答案原文作「分析匯出」 | 內容風險；答案原文若因同步暫存，**唔**餵俾分析 agent |
| 情緒日誌、錄音、相片、真名／學校／成績故事 | 憲章紅線 |
| **SEN／讀寫障礙／ADHD 等診斷標籤上雲** | 無痕支援＝本機舒適設定；雲端唔建診斷檔 |
| 跨用戶個人排名／「邊個最差」 | 禁比較羞辱；只准題目／科目聚合 |
| Session Replay 預設開 | 易錄到畫面內敏感內容 |

本機「一鍵舒適模式」等 SEN **設定**可留本地；**唔**寫成雲端 `sen_diagnosis=…`。

## 3. AI／Agent 點樣用呢啲資料

### 3.1 准做

| 分析 | 輸入 | 輸出（給創辦人） |
|---|---|---|
| 漏斗 | 週內 started／completed（按科若有） | 「邊科開始多、完成少」 |
| 阻礙 | auth_sync_error、Sentry 聚合 | 三大阻礙清單（登入／載入／題目／同步） |
| 題目優先 | 錯率／舉報／收起（題目 id） | 壞題／待審／建議下架（**唔**冒充真人教師已審） |
| 容量／成本 | Speed Insights、平台用量（若有） | 尖峰／額度風險提示 |
| 誠實未知 | 缺事件、樣本太少 | 寫入週報「未知／待研究」 |

### 3.2 禁止做

- 對單一 `user_id` 輸出「預測等級、讀書性格、SEN 推測、情緒狀態」。  
- 用答案原文／錯題 DNA 做長期個人檔案或對外故事。  
- 虛構「教師已覆核」「官方認可」「N 萬用戶實證」——無來源就寫「未知」。  
- 未批新付費模型／SDK；未批唔開 Replay。  
- 自行 wipe DB、改 production env、或對 production 做壓測／攻擊探測。

### 3.3 建議工作流（對齊 J 每週一頁）

1. Agent 只讀**白名單事件聚合**＋錯誤聚合＋題庫營運表（題目層）。  
2. 產出 `週報 YYYY-MM-DD`（香港時間）：六段骨架見 J-MIN。  
3. 每段附「樣本數／信心」；樣本不足就標待研究。  
4. 結尾三個決策必須係創辦人可拍板嘅產品／題庫／穩定項——唔係「再多追蹤學生」。

## 4. 受眾約束（免費 HK DSE）

- 功能預設**免費用晒**；分析唔可以變成付費牆或歧視 SEN／基層。  
- 文案同 agent 輸出用學生聽得明嘅繁中／英文產品語；唔用診斷標籤行銷。  
- 同意閘邏輯（若開）：不同意上雲仍可用本機——分析唔靠逼登入。
