## 1. 不可越過的安全紅線

| 類別 | Claude Code 絕不可做 | 唯一安全做法 |
|---|---|---|
| 未成年學生 | 私訊招募、WhatsApp／Signal 跟進、一對一輔導、依脆弱性挑選個案。 | 不接觸、不招募；任何例外先有 Brian／Yuna 明確批准的安全備忘。 |
