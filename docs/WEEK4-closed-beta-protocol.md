**日期：** 2026-08-23
**狀態：** 未執行。本文件只係方案，**冇任何結果**。
**執行者：** 必須真人（Brian / Yuna）。Claude 做唔到 —— 需要真實學生。

## 零、開始之前必須處理嘅三件事

### 1. 未成年人同意

測試對象係 12–18 歲。開始之前要有：

- 學生本人口頭／書面同意
- **未滿 18 歲者：家長或監護人書面同意**
- 同意書要講清楚：收集乜、點用、幾時刪、點樣退出

退出必須即時生效，唔使解釋，已收集嘅回饋一併刪除。

### 2. 唔可以收集嘅嘢（PDPO + 憲章紅線）

| 絕對唔可以收 | 原因 |
|---|---|
| 學校名、班別、學號 | 可識別個人；亦係已剷走嘅老師平台遺物 |
| 真實姓名（用代號 A–T） | 唔需要 |
| 成績、預測等級、實際 DSE 成績 | 敏感個人資料 |
| 情緒紀錄、`dse_emotion_log`、時間囊內容 | 精神健康 PII —— 憲章永久紅線，唔准離開本機 |
| 任何截圖含上述內容 | 同上 |

**平台本身唔會、亦唔應該為咗呢次測試而新增任何伺服器記錄。**
所有觀察由測試員現場筆記，寫喺紙／本機文件，唔入 Supabase。

### 3. 求助路徑要先講明

開始前逐個學生講一次：如果做嘅過程中覺得辛苦，隨時可以停，
右下角有情緒支援掣，入面有真實熱線：

- 撒瑪利亞防止自殺會 **2382 0000**（24 小時）
- 生命熱線 **2896 0000**

測試員唔係輔導員，唔好嘗試處理情緒問題 —— 停低，指返去熱線。

## 一、招募

| 項目 | 建議 |
|---|---|
| 人數 | 10–20 |
| 組成 | 至少 3 位自認做題有困難嘅學生；至少 2 位非華語考生；至少 2 位有 SEN 支援需要（自願申報，唔記錄診斷） |
| 唔好只搵 | 成績好、本身鍾意做題嗰批 —— 佢哋乜都覺得好，測唔到嘢 |
| 時長 | 每人一節 30–40 分鐘 |
| 形式 | 一對一觀察，唔好圍威喂（會互相影響答案） |

## 二、測試流程（每人 30–40 分鐘）

### A. 唔提示，淨係睇（10 分鐘）

畀學生自己開網站，**唔好教佢點用**。記錄：

1. 佢第一樣撳嘅係乜？
2. 幾耐先做到第一條題？
3. 有冇撳錯／搵唔到嘢？
4. 有冇停低皺眉？（記低係邊一版）

### B. 指定任務（15 分鐘）

逐項講，唔好示範，記錄「做唔做到 / 用咗幾耐 / 有冇問人」：

| # | 任務 | 想驗嘅嘢 |
|---|---|---|
| 1 | 做一份經濟練習，直至答錯一條難題 | 60 秒逆向鎖死流程 |
| 2 | 開「一鍵舒適模式」，再做一條題 | SEN 支援可唔可以自己搵到 |
| 3 | 開逐題計時，做到時間到 | 計時模式有冇造成壓力 |
| 4 | 喺「下一題想要」揀「基礎」 | 手動難度選擇睇唔睇得明 |
| 5 | 去「我的進度」，講出你最弱嘅課題 | 掌握度圓環讀唔讀得明 |
| 6 | 開知識概念網，講出「已建立連接」係咩意思 | 概念網會唔會被誤解成收集圖鑑 |
| 7 | 撳走一條「今日幾句建議」 | 建議有冇被當成任務 |
| 8 | 開一條長題目，用分步提示 | 提示係咪真係幫到手 |

### C. 開口問（10 分鐘）

規格書 §7.3 指定必問，逐條問，記錄原話唔好總結：

1. 計時模式令你緊張嗎？（**焦慮友善檢查**）
2. 答錯之後嗰 60 秒，你有冇試過想跳過？點解？
3. 分步提示你有冇真係用？定係直接睇答案？
4. 錯題 DNA 講嘅嘢，你覺得夠唔夠具體？有冇責備感？
5. 每日建議會唔會令你覺得有壓力／覺得欠咗嘢？
6. **有冇喺任何一版感覺到「同人比較」？**（憲章紅線檢查）
7. 概念網你覺得係一幅地圖，定係一套要儲齊嘅嘢？
8. 有邊一版令你覺得自己好差？（**最重要嗰條，一定要問**）

### D. 收尾

- 多謝佢，講明佢嘅回饋唔會影響任何嘢
- 再講一次熱線
- 問佢想唔想刪除今日嘅筆記 —— 想就即刻刪

## 四、判讀準則

呢批係質性回饋，**唔好換算成百分比**（10–20 人算唔出有意義嘅比例，
算咗就會變成虛構統計，撞憲章紅線）。

改為睇有冇出現以下訊號，**任何一條出現就要處理**：

| 紅旗訊號 | 對應紅線 |
|---|---|
| 有學生講計時令佢緊張 | 憲章第 7 條 —— 計時模式要更明顯咁標明可選 |
| 有學生想跳過 60 秒鎖 | 教學法 vs 體驗張力，要重新權衡 |
| 有學生講某一版令佢覺得自己好差 | 憲章第 7 條 —— 即刻改嗰一版 |
| 有學生感覺到同人比較 | 憲章第 8 條 —— 揾出邊度俾人咁樣讀 |
| 有學生把概念網當成要儲齊 | 規格書 §4.4 —— 文案要再講清楚 |
| 有學生覺得每日建議係任務 | 規格書 §4.5 —— 撳走機制唔夠明顯 |
| 非華語考生有版睇唔明 | 有中英夾雜漏網 |

## 五、報告格式

測試完之後出一份，**只寫觀察到嘅嘢**：

1. 每條紅旗訊號出現咗幾多次（寫實數，例：「3 位提到計時令佢緊張」）
2. 逐條原話引述
3. 任務完成情況（實數，唔換算百分比）
4. 建議修改，按紅線嚴重程度排序

**唔准寫：** 轉化率、留存率、滿意度分數、任何推算到全體考生嘅數字。
10–20 人推算唔到全港考生，寫咗就係虛構統計。
