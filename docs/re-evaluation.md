# 視覺與圖標資產複查清單 (Re-Evaluation Loop)

本文件執行第二輪自動與人工掃描，全面核查頁面之圖標可見度、空狀態插圖、識別性與觸控區域。

## 1. 複查範圍與自動化驗證標準 (Scan Criteria)
1. **可見性斷言 (Visible SVG)**：所有帶圖標之按鈕均渲染有效之向量節點，外框尺寸大於 0（bounding box > 0）。
2. **插圖覆蓋 (Illustration Coverage)**：收藏為空（`app/bookmarks/BookmarksView.tsx`）與錯誤狀態（`app/error.tsx`）均包含專屬原創向量插圖。
3. **識別大於回憶 (Recognition not Recall)**：無孤立無輔助說明的純圖標；所有按鈕皆具備文字標籤、`aria-label` 或 `title` 提示。

## 2. 審查發現清單與即時修復 (Issues & Immediate Fixes)

### A. 應該有但仲未有 (Should Have but Missing)
- **問題 1**：頂欄（Navbar）缺乏直觀的題庫檢索與科目篩選入口。
  - **修復**：於橫向導覽條補齊搜尋題目與篩選科目，圖標均配搭文字標籤，支援無障礙讀屏。
- **問題 2**：收藏按鈕點擊後缺乏系統狀態反饋（Visibility of system status）。
  - **修復**：新增 Toast 即時提示「已收藏到錯題本」，3 秒自動淡出，並附帶 `aria-live="polite"`。
- **問題 3**：收藏頁為空時缺乏情境引導。
  - **修復**：加入原創 `empty-state` 插圖，搭配「開始練習」行動按鈕。
- **問題 4**：錯誤頁僅有文字描述。
  - **修復**：加入原創 `error-state` 盾牌插圖，減低學生考試緊張感。

### B. 有咗但做得唔好 (Present but Suboptimal)
- **問題 1**：部分小圖標未達到 44px / 48px 最低觸控標準。
  - **修復**：將導航及收藏相關按鈕均維持在 `min-h-12` (48px) 或 `min-h-11` (44px)，按鈕周邊預留充足邊距。
- **問題 2**：純圖標按鈕在無鼠標懸停設備無法辨識功能。
  - **修復**：在所有核心操作補齊文字標籤及 `title` 工具提示（例如：「篩選科目、年份、難度」）。

## 3. 複查結論
- 缺失項：0
- 不良項：0
- 全部檢查項皆已在同一 PR 完成修復。
