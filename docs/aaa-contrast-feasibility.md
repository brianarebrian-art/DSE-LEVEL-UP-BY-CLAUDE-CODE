## 三、真正嘅阻礙：同色淡底藥丸

`globals.css:347` 自己寫住：

> 同色淡底藥丸（`bg-accent/[0.10]` 之類）—— Tailwind 會編譯成帶 alpha 嘅色值，
> scope 換底色之後對比會跌約 0.9，**而莫蘭迪色相本身冇呢個餘量**。

呢個唔係推測，係做過嘅事：當年為咗過 **AA**，40 處藥丸要**改結構**
（實色 `bg-ml-muted` ＋ 左側 3px 色條），唔靠 alpha；另有 69 處
「同色字疊同色淡底」逐處改成實色次級面。

換句話講：

- 純底面 → 換四個值就夠
- 淡底藥丸 → 色相已經冇餘量，要再改一次結構

所以 AAA 開關唔係一個 token 開關，係一個**組件層工程**。

## 四、點解唔照做住個一半

一個掛住「WCAG AAA」而部分位置仲係 5.0 嘅開關，對一個真係需要高對比嘅
學生嚟講**比冇開關更差** —— 佢會信佢，然後唔去開自己部機或者瀏覽器嘅
高對比模式。呢個同憲章 §16.D 嗰個判例係同一件事：
「自動攔截 3Hz 閃爍」令光敏感學生唔開自己嘅防護。

**通用規則（§16.D）：講任何無障礙功能之前先答一句 ——
「呢樣嘢喺學生部機上真係做到幾多？」** 答「一部分」就唔可以用個滿分嘅名。

## 五、三條路，建議揀第二條

| | 做法 | 代價 | 誠實程度 |
|---|---|---|---|
| A | 照換四個 token，叫佢「WCAG AAA 模式」 | 低 | ✗ 藥丸仲係 ~5.0，個名講大咗 |
| **B** | 換四個 token，叫佢「**更高對比**／Higher contrast」，介面明講唔涵蓋有色標籤底 | 低 | ✅ |
| C | 連 40 處藥丸一齊做，先叫 AAA | 高（組件層） | ✅ |

**建議 B。** 佢真係幫到手（正文輔助字由 4.98 升到 7.03），而且個名冇講大。
日後想要真 AAA，C 仍然做得，B 唔會擋住佢。

### B 要郁嘅位（同 `font-easy` 完全一樣嘅四個觸點）

1. `app/globals.css` —— `html.contrast-high` 之下覆寫嗰四個 token（淺／暗各一組）
2. `components/GlobalA11y.tsx:65` —— 開機由 localStorage 套用（`font-easy` 就係喺度）
3. `components/A11yPanel.tsx` —— 個掣（跟現有 `aria-pressed` 寫法）
4. 迴歸鎖 —— 照 `lib/__tests__/settings-have-controls.test.mts` 嗰個模式

⚠️ **刻意唔入 `lib/settingsSync.ts`。** 入咗就變成一個上雲設定，
而憲章 §16.E 執行第 1 點寫明上雲 key 要創辦人書面批准。
主題（`dse-theme`）本身都係純本機，呢個跟返佢。

### 驗收（唔可以只靠 CSS diff）

開咗之後要用 `scripts/a11y/runtime-probe.js` 把門檻由 4.5 改做 7，
重掃 34 條路由 × 2 主題，並且**逐項列出仲未夠 7 嘅位**（預期就係啲藥丸）——
列得出，先至有資格講個名叫乜。
