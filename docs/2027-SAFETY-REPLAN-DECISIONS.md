# 2027 安全重規劃：不可談判的決定

> 本文件取代任何把未成年學生作個人追蹤、私訊跟進、個案故事或增長素材的做法。它是 Claude Code 在 2026-08-24 至 2027-04-07 的強制治理層；如與舊有策略或日曆牴觸，以本文件為準。

## 一、重規劃原則

DSE LEVEL UP 的價值在於提供原創、免費、低壓、可及和可靠的學習工具，而不是讓創辦人或系統追蹤個別未成年學生的成績、困難或情緒。平台以改善產品的普遍體驗作為成功證據；不以要求學生感謝、升分、持續聯絡、公開故事或品牌背書作為目標。

任何涉及學生的研究、回饋或外部合作，必須符合 **自願、最小化、可退出、非識別、非一對一依賴、真人批准** 六個條件。只要其中一項不能保證，Claude Code 必須停止並提交待決定事項。

## 二、絕對禁止事項

| 類別 | 禁止事項 | 原因 |
|---|---|---|
| **學生接觸** | 以私訊、WhatsApp、Signal、個人帳號或一對一方式招募、跟進、輔導或追蹤未成年學生。 | 會產生未成年保障、私隱、權力界線與依賴風險。 |
| **招募與標籤** | 按基層、Band、成績、自修生、情緒狀態或其他脆弱性標籤挑選學生作「種子個案」。 | 不公平地鎖定可能較脆弱的人，也不符合最小化原則。 |
| **個人學習追蹤** | 建立、匯出、人工閱讀或持續追蹤某學生的錯題 DNA、準確率曲線、情緒日誌、作答內容或成績故事。 | 學習資料屬未成年敏感脈絡資料，不能成為產品或行銷素材。 |
| **見證與個案宣傳** | 索取、引導、包裝或發布學生見證、前後成績故事、照片、DM 截圖、可辨識引述或「感謝」內容。 | 同意未必自由、結果不可歸因，也容易形成宣傳壓力。 |
| **創辦人對外內容** | 將仍在承受的自我貶抑、孤獨或痛苦作為招募、引流或品牌內容。 | 可能把個人脆弱變為商業素材，對創辦人及受眾都不負責任。 |
| **影像與學習文化** | 美化熬夜、凌晨溫書、睡眠不足、孤獨硬撐或焦慮競爭。 | 與低壓、尊重學生健康的定位相衝突。 |
| **健康與支援聲稱** | 聲稱「醫療級」情緒安全、有人即時輔導、提供治療／診斷，或以平台代替緊急支援。 | 平台不是醫療或輔導服務，也不應作出無法履行的承諾。 |
| **外部溝通** | Claude Code 自行發出貼文、電郵、合作邀請、DM 或發佈公開數字。 | 所有對外溝通及聲稱必須獲真人單次批准。 |

## 三、可做但需嚴格條件的學生回饋

平台可以在真人批准後做 **產品可用性研究**，但目的只限改善產品，不可為行銷、個人跟進或建立學生檔案。

| 條件 | 最低標準 | 不符合時的做法 |
|---|---|---|
| 招募渠道 | 公開說明、學校／機構協作或監護人知情的渠道；不使用創辦人私訊。 | 停止招募，改做內部可用性走查。 |
| 參與性質 | 完全自願；拒絕、退出或不答問題不影響任何平台功能。 | 不啟動研究。 |
| 資料最小化 | 不收真名、學校、聯絡方式、成績、答案原文、錯題、情緒資料、相片或錄音。 | 刪除多餘欄位或取消研究。 |
| 形式 | 優先一次性、匿名的任務完成回饋；不可作創辦人與學生一對一持續關係。 | 改為公開表單或停止。 |
| 報告 | 只輸出聚合、去識別化的產品發現；不得含個案敘事、引述或可反推身分資料。 | 不對外發布。 |
| 保存與刪除 | 先寫明用途、可見者、保存期和刪除方式；用完即刪。 | 不收集資料。 |
| 批准 | 研究問題、資料欄位、文案、渠道與結果報告均由 Brian／Yuna 明確批准。 | 保留草稿，不執行。 |

## 四、低壓而負責任的內容及品牌標準

| 類別 | 可以做 | 不可以做 |
|---|---|---|
| 學生文案 | 「今日做 1 題都得」、「呢個課題值得再行一次」、「一齊由題目關鍵字拆」。 | 「你無真正理解」、「必升」、「最後機會」、「落後同學」。 |
| 影像 | 日間或正常作息下的安靜、可選擇、短時段學習；成年模特或不辨識人物／物件。 | 用可辨識未成年模特、深夜硬撐、冷咖啡、孤獨痛苦去浪漫化熬夜。 |
| 創辦人文字 | 經沉澱的產品原則：免費、原創、真人審核、私隱、低壓、可及性與公開修正。 | 將即時情緒困擾、被看見的渴求或自我貶抑寫成招募內容。 |
| 成效表述 | 「我們正在測試／改進某流程」及附方法和日期的聚合產品數據。 | 個人升分承諾、真實／虛構學生故事、未驗證排名、所謂醫療或學習保證。 |
| 支援 | 非醫療休息工具、透明外部支援導引、明示平台不是輔導服務。 | 主動分析情緒、診斷、承諾有人回覆、以平台取代專業或緊急支援。 |

## 五、Claude Code 的停止規則

Claude Code 一旦遇到以下要求，必須停止，不可「先做再問」：新學生資料欄位、研究／招募表單、追蹤或分析、學生故事／引述／相片、社交貼文／DM／電郵、外部合作聯絡、對外成效數字、危機／醫療字眼、或任何可能識別未成年學生的內容。

停止時，Claude Code 只可交付一份選項備忘：目的、至少兩個更安全替代方案、資料／保障風險、不可做項、所需真人決定。Brian／Yuna 的明確書面批准是唯一放行條件。
