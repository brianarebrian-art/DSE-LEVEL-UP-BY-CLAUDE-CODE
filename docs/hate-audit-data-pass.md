# 信任審計：仍須資料／運維處理的項目

2026-10-23 對抗式信任審計的程式修補已在版本庫內完成。學生端讀的是隨網站建置的題庫；雲端鏡像版本對不上時不會蓋過它。下面第 1、2、6 項這個拉取請求沒有做。第 3 至 5 項已在版本庫處理，仍待熟悉該科的人覆核，沒有推上 Supabase。

## 單一數字來源

學生見到的「練習中／已收起」以 `data/questions/summary.generated.ts` 的 `CONTENT_STATS` 為準。`WITHDRAWN_FOR_FAULT` 只是「已收起」之中「發現有錯」的子集。透明度頁「呢批題數」是 2026-09-29 位置詞批次（`repairStats().found`），不是目前已收起總數。

## 未執行的資料步驟

1. **雲端鏡像。** `scripts/qbank/sync-questions.mts --push` 需要 Supabase 憑證。這個環境沒有該憑證，沒有推送。題目的規範來源仍是 `data/questions/*.ts`；部署若只讀雲端鏡像，要在有憑證的環境再跑一次同步，學生端才會見到生成器已修正的題（包括數學 K5 側棱角的干擾項）。

2. **選項長度偏差。** 新題已由 `scripts/qbank/_gate.mjs` 擋住「最長選項即答案」超過門檻的題。既有題庫裡，中國歷史、中國語文、中國文學、英國文學、倫理與宗教、公民與社會發展、歷史、視覺藝術仍可能有此偏差。這個拉取請求沒有整庫重生或下架。在重生之前，上述科目以及 2027 年考卷沒有選擇題的科目，累積等級範圍不會顯示（`lib/levelEstimatePolicy.ts`）。

3. **機器閘重算的 172 題。** 已暫停放入預設練習，並在題庫狀態計為 `CONTENT_STATS.machineRestored`（與「等人手判斷」的 13 條不是同一批）。題目仍留在版本庫，收藏頁會標明未經人手覆核。這不是人手審定，頁面不會寫成「已審定」。清單由 `npx --yes tsx@4.19.2 scripts/qbank/refresh-machine-restored-ids.mts` 從 `rationale-repairs.json` 重生。熟悉該科的人覆核之後，才可以從這份清單移除並重新放入練習。

4. **文言比較題 `zh_cmp_*`。** 模板把不同寓意硬套成同一句正確答案，已停止產出，不另撰比較結論。單篇寓意題仍在。

5. **書寫題共用解析。** 「本題考核的是【由資料走到結論】」這類共用段落，學生介面改為顯示「通用自評方向」，不當作該題評卷參考。參考答案維持逐題原文。沒有逐題改寫那 400 多段空泛解析。

6. **身份與全庫人手審閱。** 不能在這個拉取請求核實「DSE 舊生」身份，也不會把全庫標成已審定。

## 重新生成清單

題庫資料變更之後：

```bash
npx --yes tsx@4.19.2 scripts/qbank/refresh-machine-restored-ids.mts
npm run gen:summary
```

`gen:summary` 的實際指令以 `package.json` 為準。雲端同步只在具備憑證、並且確認要更新正式題庫時執行。
