# docs/23-no-external-llm-policy.md

> 創辦人指示（2026-11-26）：**唔會使用任何其他額外嘅 LLM**。  
> 簽署模式：**等全部就緒後一次過簽署**（非每日抽檢簽署）。

## 政策

1. **禁止**呼叫 `FOUNDER_AI_*`、OpenAI、Anthropic、xAI 或其他第三方模型 API 作題目生成／盲審。  
2. 本 repo 內唯一允許的生成／審核執行者 = **Cursor Agent（本對話）** + **確定性腳本**。  
3. 「AI 盲審」若無第二獨立模型，必須標為 `SELF_ADVERSARIAL_DETERMINISTIC` 或 `CURSOR_DUAL_PASS`，**不得**假裝成跨模型盲審。  
4. 憲章 2B C2（付費 LLM 預算）**作廢／不申請**。  
5. 人類審核：累積至批次就緒後 **一次簽署** 才可 `APPROVED → RELEASED`；過程中可停留在 `ADVERSARIAL_PASSED`。

## 對「30 日全量 26428 + 難 10%」的影響（必須誠實）

| 資源 | 含義 |
|---|---|
| 無外部 LLM 並行 | 無法以數百題／日穩定產出經雙模型盲審的改寫 |
| 一次簽署 | 降低過程抽檢摩擦，但**不提高**學術正確性；錯誤會累積到最後 |
| 兩人非學科專家 | 最終簽署 ≠ 教師審定 |

**結論：** 在本政策下，30 日內宣稱「26428 全部難 10% 且可發布」仍然 **不可行**。可行路徑係：

1. 確定性閘 + 元數據／難度標註全量覆蓋  
2. Cursor 分批實質改寫高頻／高風險題（可驗證、可回滾）  
3. 其餘維持 `LEGACY_UNCALIBRATED` 直至有證據升級  
4. 創辦人對**已就緒批次**一次簽署發布，而非對未驗證全庫簽署

禁止為趕簽而把未過閘題目標成 `RELEASED`。
