# DSE LEVEL UP 2027：安全優先的考季作戰策略

> **有效期：2026-08-24 至 2027-04-07。** 2027 HKDSE 中國語文卷一、卷二安排於 2027-04-08（星期四）上午；考前最後四日只容許必要修正。[1]

## 一、重新定義領先：值得被信任，才值得被使用

DSE LEVEL UP 不把「最多人用」或「全港第一」當作可自行宣稱的目標，而是以可核查的產品可靠性、內容原創性、免費承諾、學生尊重、無障礙與透明修正來贏得使用。市場地位只可在有獨立、可驗證證據後描述；在此之前，所有公開語言必須是正在做、已驗證功能與可追溯決定。

平台的安全底線不會為增長讓步。未成年學生不是試驗對象、個案故事、見證資產或可被長期追蹤的數據來源。學習的「下一步」應在學生自己裝置上產生；平台不應收集、匯出或人工閱讀個人的錯題、成績、作答內容或情緒資料。具體治理規則見 `docs/2027-SAFETY-REPLAN-DECISIONS.md`。

| 成功面向 | 2027-04-07 前要建立的證據 | 明確不做的事 |
|---|---|---|
| **內容可信** | 每條新題有 2027 框架對照、原創性說明、機械閘與真人簽核。 | 抄錄官方／第三方題目、以題數替代品質、讓機器自動入庫。 |
| **學生尊重** | 學生流程每一步有無壓力退出、具體下一步及可及性走查。 | 焦慮倒數、紅叉羞辱、排名、強迫回訪或自動心理推論。 |
| **私隱最小化** | 預設不新增用戶遙測；每個資料改動均有獨立風險備忘與真人決定。 | 個人錯題 DNA、成績曲線、情緒紀錄、答案原文或可識別試點資料。 |
| **可靠交付** | 測試、QA、build、預覽、回滾、錯誤修正與官方資料核對均可重複。 | 未測試部署、無回滾、把規劃中功能宣稱為已上線。 |
| **負責任對外溝通** | 只準備經核對的資產與透明說明；所有實際發布由真人單次批准。 | 私訊學生、發見證、發個案故事、發未核對數字、將脆弱當行銷。 |

## 二、唯一北極星：安全完成一個練習閉環

在不收集個人學習資料的前提下，平台的首要產品問題是：一名學生能否自主完成「選擇適合練習 → 作答 → 看見非責備的下一步 → 選擇覆習或休息」？因此，工程與內容工作的第一優先是把這個閉環做到清楚、可中斷、可返回、無障礙和可靠。

任何使用量、留存或完成率資料都不是預設目標；如日後提出量度，必須先由 Brian／Yuna 逐項批准目的、資料字典、拒絕選項、保存期、刪除和公開說明。在未批准前，所有產品決定均以內部任務劇本、程式測試、人工走查、題庫審核與公開來源核對為證據。

## 三、八個安全戰役

| 戰役 | 日期 | 核心工作 | 出關條件 |
|---|---:|---|---|
| **A. 治理與真實基線** | 08-24 至 09-13 | 建立安全決定、品質基線、資料邊界、台帳與停止規則。 | Claude Code 已載入安全協議；無未批准資料／對外行動。 |
| **B. 自主學習閉環** | 09-14 至 10-11 | 改善開始、答錯後下一步、覆習、休息與可返回流程。 | 一條核心旅程通過手機、鍵盤、縮放、減少動態及錯誤狀態走查。 |
| **C. 原創內容治理** | 10-12 至 11-15 | 建立中文及跨科的覆蓋矩陣、草稿、真人審核及題庫完整性。 | 新內容只在簽核後入庫；長答維持自評、非自動改卷。 |
| **D. 無障礙與可靠性** | 11-16 至 12-27 | 改善低刺激、閱讀、錯誤處理、離線／同步降級及回滾。 | 主要流程可在可及性情境下完成；P0 分流與回滾可演練。 |
| **E. 信任資產準備** | 12-28 至 01-31 | 準備來源、政策、官方資源導覽、公開修正與成年／非辨識視覺指引。 | 所有草稿經事實、私隱、版權與語氣檢查；不自動發布。 |
| **F. 內部考季驗證** | 02-01 至 03-07 | 以內部任務劇本和已審原創內容測試完整練習、中文資源與事故流程。 | 無需接觸或追蹤學生，仍可完成核心流程修正。 |
| **G. 中文 30 日安全支援** | 03-08 至 04-03 | 原創中文練習、官方資料核對、無障礙、低壓文案、內容更正。 | 所有學生可見中文內容有來源、免責、回報與修正途徑。 |
| **H. 考前四日穩定期** | 04-04 至 04-07 | 只維持可用、正確、低壓與可回滾。 | 沒有新功能、沒有外部活動、沒有未審內容或資料收集。 |

## 四、內容與產品的優先順序

| 優先序 | 可以排期的工作 | 要延後或停止的工作 |
|---:|---|---|
| **P0** | 官方面試／考期資料正確、站點可用、錯誤答案鍵、危機資訊、資料遺失風險。 | 一切不直接影響安全與可用性的功能。 |
| **P1** | 原創題庫審核、中文考前路線、答案解析、無障礙阻斷、覆習／休息出口。 | 未核對的內容擴張、分數預測、競賽化與排行榜。 |
| **P2** | 信任頁、來源台帳、公開修正紀錄、非辨識視覺規範、內部運維文件。 | 學生試點、個案研究、私訊社群、社交媒體發文或外聯。 |
| **P3** | 只在明確安全批准後研究的選項，例如一次性、匿名、最小化的產品回饋。 | 沒有批准的任何資料收集、招募、外部接觸或行銷實驗。 |

## 五、對外內容與影像的安全路線

平台可以準備內容，但製作與發布必須分開。Claude Code 可建立「待批准資產」：來源導覽、平台原則、如何開始的教學卡、修正政策、無障礙功能說明及不辨識學生的學習環境插圖指引。所有資產必須在發布前由真人確認事實、版權、語氣、影像人物年齡與同意狀況、連結及日期。

影像只可呈現健康、低壓、可自主結束的學習：自然光／正常作息、空間與物件、成年模特或完全無法辨識身份的畫面。不可把深夜孤獨、過勞、冷咖啡或崩潰感塑造成 DSE 值得追求的美學。創辦人公開文字只可寫經沉澱的產品選擇與可核對事實，不能把未處理的個人痛苦轉化為吸引力。

## 六、每日工作的最低交付標準

| 步驟 | Claude Code 必做 | 通過標準 |
|---|---|---|
| **界定** | 寫清目標、非目標、受影響路徑、安全檢查、驗收和回滾。 | 十行內；沒有模糊的學生接觸或資料收集。 |
| **實作／整理** | 做最小改動；每個改動可獨立驗證。 | 不改資料邊界、不混入未批准功能。 |
| **驗證** | 按範圍跑 lint、test、qa、budget、build；學生流程另走查可及性。 | 結果可重複；失敗如實記錄。 |
| **停止與批准** | 遇資料、學生、外聯、見證、影像人物、公開聲稱即停。 | 提交替代方案與所需真人決定；不先做再問。 |
| **證據包** | 記錄變更、測試、風險、回滾及明天唯一主指令。 | 可由第三方複查，且無機密或個資。 |
