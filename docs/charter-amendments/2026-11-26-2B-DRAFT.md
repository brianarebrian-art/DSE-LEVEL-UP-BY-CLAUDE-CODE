## C1 — 伺服器端出題／評分（試點）

1. 新增 `POST /api/practice/session`：回傳 sessionId、洗牌後選項、題幹；**不含** `correctIndex`、`explanation`、`referenceAnswer`。  
2. 新增 `POST /api/practice/grade`：server 評分；回傳對錯與解析（僅提交後）。  
3. 靜態 chunk／離線回落路徑：試點科可暫時保留舊路徑並標 `LEGACY_CLIENT_KEY`；切斷全庫 anon 須獨立批准。  
4. 信任文案維持「未經註冊教師審定」。

## C2 — 外部 LLM：**取消**（創辦人 2026-11-26）

創辦人指示唔使用任何額外 LLM。C2 原「付費 LLM 預算」條款**不作申請、不生效**。  
題目生成／對抗審核只允許：Cursor Agent + 確定性腳本。詳見 `docs/23-no-external-llm-policy.md`。

## C3 — 匿名校準事件字典

**可寫入（最小必要）：**

- `item_id`, `session_anon_id`（隨機，非 user uuid）, `subject`, `topic`  
- `is_correct`（boolean）, `latency_ms`, `difficulty_tag`, `client_day`（日期無時區精確到日）  
- `practice_mode`（enum）

**禁止寫入：** email、姓名、IP、精確 GPS、健康／情緒診斷、螢幕錄影、未同意之自由文字。

**同意：** 沿用 `privacy_consents`；新目的碼 `calibration.v1`；可撤回後停止寫入新事件（已寫入聚合可保留去識別統計）。
