## 草稿怎樣寫

升級只用來源題的編號、課題、題型、分值與基準剖面，不把來源題幹寫進倉庫。每個課題用一個可覆算的自編模板：數字與情境隨題號變化，答案由同一套算式再算一次。模板實作的是已定稿的升級要求（兩個認知要求、公平陷阱、課綱內、公式 (1) 不向下取整），不是逐題自由撰寫，也不是官方試題改寫。

擬評分按題型剖面固定，只在算術上跨過公式 (1)。選擇題是 13 分（門檻 12.1），甲部(1) 是 14 分（門檻 12.1），甲部(2) 是 17 分（門檻 16.5），乙部是 20 分（門檻 19.8）。這仍是未驗證的擬評。

Loop 3 是九項清單的可重現檢查，不呼叫付費模型。軟項若是「無法判斷」，不會改寫成通過，也不會只因這一個軟項回爐。正確性、可解性、課綱、原創性若是「無法判斷」，會回爐。本批沒有觸發回爐；回爐行為由測試鎖定。

## 練習池與 #259 overlay

`loadSubjectQuestions` 預設會套用 `data/questions/overlays/`。`lib/practice/bankCache.ts` 的 `loadBank` 沒有傳 `skipUpgradeOverlay`。`/api/practice/catalog` 與 `/api/practice/check` 都經 `loadBank`。所以 #259 的全庫 overlay 已在學生練習的載入路徑上。`RELEASED` 仍是 0。本批不修改、不撤回該 overlay。

抽樣時略過 overlay 的題號集合，與預設載入的題號集合相同。至少一條抽樣題在套用 overlay 前後的題幹雜湊不同，見隔離紀錄的雜湊，不抄題幹。

第 5–8 星期草稿的編號前綴是 `loop-w58-`。它們只放在 `data/loop-engineering/`，沒有登記進 overlay 或題庫 loader，所以不會經練習 catalog 或 check 送出。
