# 審核流程（定稿）

狀態：2026-11-27（香港時間）定稿。第三人可以只按本頁，加上量表與三份可複製文件，執行升級、AI 初審與兩人覆核。不必打開程式才知道閘門。

這不是資深 HKDSE 學科教師雙審。現況沒有兩名資深學科教師。Loop 4 是兩人批次覆核。專家表在 `prompts/expert-review-future.md`，未啟用，不得用來把題目標成可上線。

難度宣稱維持「未驗證」。不得把任何題目標成「已達 DSE+10%」或「已驗證 DSE+10%」。量表見 `rubric-zh-hk.md`。

禁止在 Prompt、評語、表格或紀錄裏要求、貼上、引用或改寫官方真題文本。若材料裏出現疑似官方試題文本，停止，只交人工法務檢視，不要複述題文。

## 狀態

`loop2_draft` → `loop3_ai_first_review` → `loop4_two_person_review` → `preview`

預覽的 `published` 維持 false。沒有再批准，不上正式站，也不上 dselevelup.com／www.dselevelup.com。

Loop 5 真實學生實測不是可儲存狀態。任何進入實測或發放問卷的嘗試都回報「待批准」，而且不改變原狀態。問卷在 `prompts/questionnaire-blocked.md`。

## Loop 3：AI 初審是硬閘

AI 初審未通過，不得進入人手覆核，更不得上正式站。

使用 `prompts/ai-review.md` 裏可複製的 Prompt。九項都只准填：通過、不通過、無法判斷。

### 一票否決（必須回爐，不得進入 Loop 4）

- 九項之中任何一項為「不通過」。
- 正確性、可解性、課綱對齊、原創性任何一項為「無法判斷」。

九項全部為「通過」，狀態才是「可交人手覆核」。

題意清晰、陷阱質量、解析質量、難度工程、披露與用語若為「無法判斷」，而沒有任何「不通過」，且上面四項都是「通過」：仍可交人手覆核。該項不得寫成已通過，必須寫進「建議人手覆核時特別注意的地方」。

回爐後再送審，先前的 AI 通過失效，必須整份重審。

## Loop 4：兩人批次覆核

使用 `prompts/two-person-review.md` 的精簡表。兩欄覆核人必須是兩個不同欄位。

簽署種類只准 `scaffold_not_subject_teacher`。兩欄覆核人不是獨立學科教師。結論不得寫成「教師審核通過」、「專家可上線」或「已達 DSE+10%」。

預覽題必須在同一處標明「未經 HKDSE 學科教師審核」。

每人每個工作日細審約 10 至 15 條。不要為趕進度跳過清單。

### 一票否決（不得勾「可留預覽」）

清單任何一項未過、擬評綜合分未達公式 (1)、或加分只靠超綱或運算量，都不得留預覽。結論改為回爐，或建議淘汰／交法務。

可留預覽還要同時滿足：AI 初審仍是「可交人手覆核」、公式 (1) 由合資格的五維分達到、披露標示正確、`published` 為 false、難度宣稱為「未驗證」。

## 回爐規則

1. AI 初審一票否決：退回 Loop 2。不得進入 Loop 4。
2. 兩人覆核結論是回爐，或建議淘汰／交法務：退回 Loop 2，並使先前的 AI 通過失效。再送審必須重新做 Loop 3。舊的通過不能直接進入人手覆核。
3. 覆核清單未全部通過，不得把結論寫成可留預覽。
4. 擬評綜合分未達公式 (1)，或加分不合格，不得進入預覽。
5. 預覽題若被退回，同樣回到 Loop 2，並要重新初審後才能再覆核。
