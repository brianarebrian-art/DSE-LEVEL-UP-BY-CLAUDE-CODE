# 兩人批次覆核表（現況使用）

現況沒有兩名資深 HKDSE 學科教師。本表是批次覆核，結論不得寫成教師審核通過，也不得寫成已驗證的難度達標。

```
DSE Level Up 兩人批次覆核精簡表（現況使用）
覆核人：__________    日期（香港時間）：__________    題號：__________
聲明：本覆核不是 HKDSE 學科教師審核。結論不得寫成「專家可上線」或「已達 DSE+10%」。

逐項（不合格者回爐）
[ ] 題意清晰、可解、無漏條件
[ ] 答案、選項、解析一致，計算無誤
[ ] 看不到超綱
[ ] 解析含推理鏈、關鍵步驟、常見錯因、可遷移方法
[ ] 至少一個可教且公平的陷阱
[ ] 五維綜合分 ≥ 基準 × 1.10，且不是只加運算量
[ ] 無改寫真題或貼上官方題文的跡象

結論
[ ] 可留預覽（必須同步標明：未經 HKDSE 學科教師審核）
[ ] 回爐（必修改要點：__________）
[ ] 建議淘汰或交法務

產能提醒：每人每個工作日細審約 10 至 15 條，不要為趕進度跳過上列任何一項。
```

程式內的第 1–2 星期簽署種類固定為 `scaffold_not_subject_teacher`，並記錄兩欄覆核人並非獨立學科教師。
